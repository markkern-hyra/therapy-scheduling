# access Specification

## Purpose
Хто бачить застосунок без входу або без ролі: відвідувач без входу — лише сторінку входу, користувач без ролі — лише
повідомлення, що доступу ще немає; ні тому, ні іншому дані клієнтів і утримань не показуються.

## Requirements

### Requirement: Без входу — лише сторінка входу

IF користувач, який не увійшов у застосунок, відкриває за прямим посиланням список клієнтів, картку клієнта або список утримань, THEN the system SHALL показати лише сторінку входу без жодних даних клієнтів чи утримань і не змінювати жодної картки.

#### Scenario: AC-CARD-07 Пряме посилання без входу

- **GIVEN** користувач не увійшов у застосунок
- **WHEN** він відкриває за прямим посиланням список клієнтів, картку client6 або список утримань
- **THEN** він бачить лише сторінку входу, жодних даних клієнтів чи утримань не показано
- **AND** жодна картка не змінилася

### Requirement: Без ролі — лише повідомлення

IF користувач увійшов у застосунок, але не має ролі, THEN the system SHALL показувати йому лише повідомлення «Your account has no access yet. Contact an administrator.», без жодних даних клієнтів, і не змінювати жодної картки.

#### Scenario: AC-CARD-11 Користувач без ролі

- **GIVEN** користувач newuser1@example.test увійшов, але не має ролі
- **WHEN** він відкриває застосунок або картку client6 за прямим посиланням
- **THEN** він бачить лише повідомлення «Your account has no access yet. Contact an administrator.», жодних даних клієнтів не показано
- **AND** жодна картка не змінилася
